# DQM2SP Tools 配布・障害報告

「ドラゴンクエストモンスターズ2 イルとルカの不思議な鍵SP」で、非公式のオンライン対戦環境を利用するための配布物と障害報告窓口です。

本リポジトリは非公式の個人プロジェクトです。
株式会社スクウェア・エニックスをはじめとする権利者各社とは関係ありません。

## ダウンロード

配布物は[最新のRelease](https://github.com/genie-kz/dqm2sp-tools/releases/latest)から取得できます。

ReleaseのAssetsにある `dqm2sp-tools-*.zip` が利用者向けの配布物です。
GitHubが自動生成する「Source code (zip)」「Source code (tar.gz)」にはツール本体が含まれません。

配布ZIPには次のものが入っています。

- Android上で、端末にインストール済みの公式1.0.7を取り出し、代替サーバーへ接続するAPKを作るパッチャー
- 停止済みBlueStacksから公式版のセーブを読み取り専用で取り出すWindows x64ツール
- 導入、セーブ移行、更新、失敗時の対処を説明するHTML

公式APK、OBB、セーブデータ、署名用の秘密鍵は配布ZIPに含まれません。

## 利用前に確認すること

- 小規模な公開テストとして提供しています。継続運用や常時利用できることは保証していません。
- パッチャーが対応するのはGoogle Play版の公式APK 1.0.7です。
- Windows版セーブ取出ツールで確認済みの環境は、Windows 10または11のx64と、BlueStacks 5.22.255.1014のNougat 64-bitです。
- 公式版、生成したAPK、セーブのバックアップ、署名鍵、復元キーは、作業が終わるまでそれぞれ保管してください。
- オンライン機能の提供に必要な識別情報、対戦情報、ランキング情報、直近のクラウドセーブをサーバーへ保存します。利用者自身による削除機能と個別の削除受付は用意していません。

オンライン他国マスターの更新と通信お見合い用データの取得は、公式サーバーへ接続します。対戦と復元キーによるクラウドセーブは代替サーバーを利用します。

詳しい手順と現在の確認範囲は、配布ZIP内の `README.html` を参照してください。

## 障害を報告する

障害を見つけた場合は、[障害報告フォーム](https://github.com/genie-kz/dqm2sp-tools/issues/new/choose)から報告してください。
報告にはGitHubアカウントへのログインが必要です。

Issueと添付内容は誰でも閲覧できます。
Friend Code、復元キー、認証情報、セーブデータ、個人情報を投稿しないでください。
ログや画像を添える場合は、公開してよい範囲だけを切り出し、識別子を伏せてください。

報告を受けても、すべての環境での再現や修正時期を約束するものではありません。
